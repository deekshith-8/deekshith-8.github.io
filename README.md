## Overview

A clean, responsive personal portfolio built from scratch. Features a dark space theme with monospace typography, showcasing projects, certifications and contact — designed to make a strong first impression with recruiters and collaborators.

---

## Sections

- **Hero** — Introduction and quick links
- **Projects** — Featured work with live demo and GitHub links
- **Skills** — Tech stack and tools
- **Certifications** — Verified credentials with modal preview
- **Contact** — Direct contact form via Formspree

| Layer | Technology |
